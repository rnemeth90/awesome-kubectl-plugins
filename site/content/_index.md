---
title: "kubectl-plugins"
---

A set of small, single-purpose [kubectl plugins](https://kubernetes.io/docs/tasks/extend-kubectl/kubectl-plugins/) written in Go.

- **`kubectl count`** counts resources of any type.
- **`kubectl unhealthy`**, **`kubectl restarts`** and **`kubectl images`** find problem pods, rank restarts and audit image tags.
- **`kubectl nodepool`**, **`kubectl aks`**, **`kubectl aks-versions`** and **`kubectl aks-maintenance`** manage Azure Kubernetes Service from kubectl.

Start with [Install](install/), then pick a plugin below.
